# Password vocabulary sources

The v10 expansion adds **200 new Basic words**: 100 nouns, 60 verbs, and
40 adjectives. All 500 previous Basic words are retained. Advanced still
has the same 150 words.

## Web references

- [Cambridge English wordlist (2025)](https://www.cambridgeenglish.org/Images/506166-starters-movers-flyers-word-list-2025.pdf): 180 additions.
- British Council exercises: 20 additions from [farm animals](https://learnenglish.britishcouncil.org/free-resources/vocabulary/a1-a2/farm-animals), [everyday objects](https://learnenglish.britishcouncil.org/free-resources/vocabulary/a1-a2/everyday-objects), and [meals and cooking](https://learnenglish.britishcouncil.org/free-resources/vocabulary/a1-a2/meals-cooking).

References checked November 5, 2026. These sources inform vocabulary
familiarity; suitability for Password is an editorial choice.

## Selection policy

Prefer everyday words that offer several spoken one-word clue routes.
When uncertain, favor the simpler choice; familiar borderline words go
in Basic. Use single words, normalize to lowercase, check both decks for
duplicates, and avoid adding regional spelling variants of existing
entries. Exclude proper names, inflected duplicates, specialist terms,
and function words with weak clue potential.

For example, **whistle** allows associations such as referee, tune, and
bird; **glue** allows paste, stick, and craft. **Bicycle** was already in
Basic, so the shorter label “bike” was not added.

The runtime bank remains independent from French Toast and is bundled
for offline use. Updating Basic requires no change to the game rules.
